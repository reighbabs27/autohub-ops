AWS infrastructure design

Everything runs in one AWS account (482882341880) in ap-southeast-2, Sydney. The diagram shows every service we run and the path a customer's question takes, numbered ① to ⑦.

How a question travels

  1. ① The customer types a question at https://dd56jth94yne6.cloudfront.net. The browser sends it over HTTPS to CloudFront.
  2. ② CloudFront forwards it, without caching, to the EC2 instance's Elastic IP on port 3080. The security group only accepts traffic from CloudFront's own address list.
  3. ③ When LibreChat starts, start-autohub.sh reads every secret from Parameter Store using the instance role, and reads the dealership content from S3. It then builds the system prompt.
  4. ④ LibreChat sends the system prompt, the conversation and the question to Google's Gemini API over HTTPS.
  5. ⑤ Gemini streams the answer back.
  6. ⑥ LibreChat stores the conversation in MongoDB, and Meilisearch indexes it for chat search.
  7. ⑦ The answer streams back through CloudFront to the browser.

Grey dashed arrows are operations traffic. The instance ships logs and metrics to CloudWatch, alarms go to SNS and then email, and backups go to S3. We reach the instance only through Systems Manager, never SSH.
